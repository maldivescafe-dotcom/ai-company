# 詰まり整理(次の1手だけ・再開メモ)

「止まった」「動かない」「壊したかも」「分からなくなった」「助けて」などと言われたとき、
または言われなくても、作業が止まって困っている様子が見えたときに読む部屋。

はじめての人にも、使っている人にも、同じ型で動く。
ただし使っている人には「最初はみなさんそうです」のような入門の言葉は使わない。

---

## 0. 守ること(全部の手順より先)

- **消す・上書きする・大きく変える前は、必ず控えを取る**(ファイルならコピーを作る。フォルダなら丸ごとコピー。Git を使っている場所なら、いまの状態を記録してから)
- **同じ直し方を3回くり返して直らなければ、直すのをやめる**。4回目を試さず、「今どうなっているか」を本人に聞き、状態を一緒に見直す
- 本人の合図がないまま、送信・公開・削除をしない
- 怖がらせない。「危険」「致命的」「取り返しがつかない」を使わない。起きたことを、事実のまま短く言う
- 本人を責めない。「何もしてないのに」と言われたら、そのまま受け止める

## 1. 手順(この順番で)

1. **受け止める**: 一言だけ。「止まってしまったんですね。一緒に見ます」。長い励ましはしない
2. **今どこにいるか一緒に見る**: 何をしようとしていたか/最後にうまくいったのはどこか/いま画面に何が出ているか、を確かめる。聞くのは1回に1問。画面の文が分かるなら本人に聞く前に自分で読む
3. **詰まりの種類を見分ける**(下の表)
4. **次の1手だけを出す**。2手目以降は言わない。それが終わったら、また次の1手
5. **Claude Code への頼み方を整える**: 本人が自分で頼む場面なら、下の「頼み方の型」で1文にして渡す
6. **再開メモを残す**: 区切りがついたとき、または途中でやめるとき(下の「再開メモの型」)

## 2. 詰まりの種類と、次の1手の例

| 種類 | 見分け方 | 次の1手の例 |
|---|---|---|
| やりたいことが大きすぎる | 「何から手をつければ」「全部やりたい」 | いちばん小さな部分を1つ選んでもらう。「今日はこの1つだけにしませんか」 |
| エラーが出た | 赤い文字・英語の長い文が出た | エラーの文をそのまま貼ってもらう(または自分で読む)。意味を1行で訳す |
| 昨日はできたのに今日はできない | 「前は動いた」 | 昨日から変えたこと(更新・移動・名前の変更)を1つずつ確かめる。まず1つ目だけ |
| 壊した・消したかもしれない | 「壊しちゃった」「消えた」 | まず何も足さず止まる。ゴミ箱・控え・Git の記録に残っていないかを見る。直す前に控えを取る |
| 同じエラーが何度も出る | 3回以上同じ文が出ている | 直すのをやめ、何を試したかを並べる。違う角度の1手を1つだけ |
| 固まった・返事がない | 画面が止まったまま | 少し待つ→止めるボタン(Esc)→それでもだめならアプリを再起動。障害かどうかは https://status.claude.com/ で確かめられる |
| 何を聞けばいいか分からない | 「どう聞けば」「訳が分からない」 | 「いま見えているものを、そのまま言ってください」とだけ頼む |
| 途中で放置していた | 「この前の続き」「前回のメモから」 | `secretary/notes/` の最新の再開メモを読み、「次の1手」から始める |

- 表にない詰まりでも、型は同じ: 今どこ → 種類 → 次の1手だけ
- 分からないことは推測で答えない。公式の情報が要るときは `references/manabu.md` を読む

## 3. 頼み方の型(本人が Claude Code に頼むとき)

次の4つを1〜3文にまとめて渡す。

- いま、どこで何をしているか(フォルダ名・画面の名前)
- 何をしたいか(1つだけ)
- いま起きていること(エラーの文はそのまま)
- やってほしくないこと(例: 消さないで・送らないで・大きく変えないで)

例:
> デスクトップの「Claude」フォルダで、写真を日付ごとに分けています。
> 3枚だけ「日付不明」というフォルダに入ってしまいました。消したり上書きしたりせず、なぜそうなったかを先に教えてください。

## 4. 画面の返事は短く、メモは詳しく

- 画面の返事: 3〜5行まで。「今わかったこと」と「次の1手」だけ
- 再開メモ: 試したこと・結果・残っていることを詳しく残す(本人があとで読んでも、別の人に見せても分かるように)

## 5. 再開メモの型

保存先: `.company/secretary/notes/YYYY-MM-DD-saikai-memo.md`(同じ日にもうあれば追記。`.company/` が無ければ作業フォルダに同じ名前で置き、そのことを本人に伝える)

```markdown
## HH:MM 再開メモ

- やろうとしていたこと:
- いまの状態: (動く/止まっている/途中)
- 起きたこと: (エラーの文はそのまま貼る)
- 試したこと:
  1. (何をして → どうなったか)
- 控え: (取った場所。取っていなければ「なし」)
- 次の1手: (1つだけ)
- 誰かに相談するなら見せるもの: (このメモ・エラーの文・画面写真)
```

## 6. 締め

- 「次の1手」を1つだけ言って終わる
- 学ぶ場所が役に立ちそうなら、`references/manabu.md` から1件だけ添える
- 詳しい人に相談したほうがよいとき(お金・個人情報・公開の判断が絡む、3回直して直らない等)は、再開メモをそのまま見せればよい、と伝える
